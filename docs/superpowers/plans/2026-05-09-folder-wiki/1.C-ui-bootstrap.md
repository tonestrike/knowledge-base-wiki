# Slice 1.C — UI bootstrap (design system + component skeletons)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Parallel-safe with 1.B** (after 1.A's Risk Report lands). Disjoint scopes — 1.B touches `packages/domains/`, 1.C touches `apps/web/`. Use `superpowers:dispatching-parallel-agents` to launch them together.

**Goal:** Stand up the design system and skeletal components for the six spectacular elements in spec §4.3 against the contract mocks from 0.1, so Phase 2.E can drop in real data and final polish without re-architecting structure or tokens.

**Architecture:** `apps/web/` adopts Tailwind 3.x + shadcn/ui (Radix primitives, copied source) + Framer Motion 11.x. Design-system tokens (colors / typography / spacing / motion per spec §4.2) live in `tailwind.config.ts` + `apps/web/src/styles/tokens.css`. A live `/design-system` route (no Storybook overhead) renders every component in every state, sourcing data from `@package/contracts/<ctx>` mock factories. React Router 6.x for routing. The closed `Artifact` component registry maps the 8 `ArtifactKind`s to React components — this is the second-leap surface.

**Tech Stack:** Tailwind 3.4.x, `tailwindcss-animate`, `class-variance-authority`, `clsx`, `tailwind-merge`, Radix UI primitives via shadcn copy-paste (`@radix-ui/react-dialog`, `@radix-ui/react-tooltip`, `@radix-ui/react-scroll-area`, `@radix-ui/react-tabs`, `@radix-ui/react-toast`), shadcn-style utilities (we don't pull a registry; we copy components in), `framer-motion` 11.x, `react-markdown` 9.x + `remark-gfm`, `recharts` 2.x, `react-router-dom` 6.x, `lucide-react` for icons, `pdfjs-dist` 4.x.

// apps/web/src/components/ui/button.tsx
import { Slot } from '@radix-ui/react-slot';
import { type VariantProps, cva } from 'class-variance-authority';
import { type ButtonHTMLAttributes, forwardRef } from 'react';
import { cn } from '../../lib/cn.ts';

const buttonVariants = cva(
  'inline-flex items-center justify-center gap-2 whitespace-nowrap rounded-md text-sm font-medium ring-offset-background transition-colors focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2 disabled:pointer-events-none disabled:opacity-50',
  {
    variants: {
      variant: {
        default: 'bg-foreground text-background hover:bg-foreground/90',
        ghost: 'hover:bg-muted',
        outline: 'border border-input bg-background hover:bg-muted',
        accent: 'bg-accent text-accent-foreground hover:bg-accent/90',
      },
      size: {
        default: 'h-10 px-4 py-2',
        sm: 'h-9 rounded-md px-3',
        lg: 'h-11 rounded-md px-8',
        icon: 'h-10 w-10',
      },
    },
    defaultVariants: { variant: 'default', size: 'default' },
  },
);

export interface ButtonProps
  extends ButtonHTMLAttributes<HTMLButtonElement>,
    VariantProps<typeof buttonVariants> {
  asChild?: boolean;
}

export const Button = forwardRef<HTMLButtonElement, ButtonProps>(
  ({ className, variant, size, asChild = false, ...props }, ref) => {
    const Comp = asChild ? Slot : 'button';
    return <Comp ref={ref} className={cn(buttonVariants({ variant, size, className }))} {...props} />;
  },
);
Button.displayName = 'Button';

export { buttonVariants };
```

interface FlightCtx {

  close: () => void;
  active: Citation | null;
}

const Ctx = createContext<FlightCtx | null>(null);

export const CitationFlightProvider = ({ children }: { children: ReactNode }) => {
  const [active, setActive] = useState<Citation | null>(null);
  const open = useCallback((c: Citation) => setActive(c), []);
  const close = useCallback(() => setActive(null), []);
  return (
    <Ctx.Provider value={{ active, open, close }}>
      {children}
      <CitationModal />
    </Ctx.Provider>
  );
};

export const useCitationFlight = () => {
  const v = useContext(Ctx);
  if (!v) throw new Error('CitationFlightProvider missing');
  return v;

          <XAxis dataKey="x" />

// apps/web/src/components/lint/lint-ribbon.tsx
import type { LintFinding } from '@package/contracts/verification';
import { Button } from '../ui/button.tsx';
import { motion } from 'framer-motion';

const verdictTone: Record<LintFinding['verdict'], string> = {
  supported: 'border-verdict-supported/40 bg-verdict-supported/5',
  unsupported: 'border-verdict-unsupported/40 bg-verdict-unsupported/5',
  contradicted: 'border-verdict-contradicted/40 bg-verdict-contradicted/5',
};

export function LintRibbon({
  finding,
  onApply,
}: {
  finding: LintFinding;
  onApply: (id: string) => void;
}) {
  return (
    <motion.aside
      initial={{ opacity: 0, y: -8 }}
      animate={{ opacity: 1, y: 0 }}
      className={`rounded-lg border ${verdictTone[finding.verdict]} px-5 py-4`}
    >
      <p className="font-mono text-[10px] uppercase tracking-widest">
        Verdict: {finding.verdict}
      </p>
      <div className="mt-3 grid grid-cols-2 gap-6">
        <div>
          <p className="font-mono text-[10px] uppercase tracking-widest text-muted-foreground">Claim</p>
          <p className="mt-1 font-serif text-sm">{finding.claim.claimText}</p>
        </div>
        <div>
          <p className="font-mono text-[10px] uppercase tracking-widest text-muted-foreground">Cited span</p>
          <p className="mt-1 font-serif text-sm">{finding.evidenceText}</p>
        </div>
      </div>
      {finding.correction ? (
        <div className="mt-4 border-t border-border pt-4">
          <p className="font-mono text-[10px] uppercase tracking-widest text-muted-foreground">Correction</p>
          <p className="mt-1 font-serif text-sm">
            <span className="text-verdict-contradicted line-through">{finding.claim.claimText}</span>{' '}
            <span className="text-verdict-supported underline-offset-2 decoration-2">
              {finding.correction.replacementText}
            </span>
          </p>
          <Button
            onClick={() => onApply(finding.id)}
            variant="accent"
            size="sm"
            className="mt-3"
          >
            Apply correction
          </Button>
        </div>
      ) : null}
    </motion.aside>
  );
}
```
