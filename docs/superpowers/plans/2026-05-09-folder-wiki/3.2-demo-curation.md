- [ ] **Step 2: Plant the contradiction**

In `03-q3-metrics-deck.md`, write the metrics table such that "Q3 NRR landed at **105%**, four points below the 109% target."

The Drafter will pick one of the two as the canonical Decision/Metric page; the other acts as the contradicting cited span. The Verifier should catch the discrepancy when one page's Claim cites a span from the other doc.

> Subtlety check: don't make the contradiction a literal copy-paste mistake. The Drafter has to draw a Claim from one doc but use a citation from the other (which the Researcher will sometimes do because both docs talk about NRR). On replay, if the Drafter doesn't make that mistake naturally, hand-edit the Drafter prompt for this demo folder to bias toward citing the metrics deck for the NRR claim — that's a fair "demo cadence tuning" choice and is documented in `demo-folder.md`.

## Task 2: Tune compile cadence

**Goal:** End-to-end compile feels responsive. Storyboard target: under 60 seconds wallclock.

- [ ] **Step 1: Run a clean compile against the seeded folder**

```bash
bun --filter @app/api dev
# In another shell:
curl -X POST http://localhost:8787/rpc/wiki/startCompile -H 'content-type: application/json' -d '{"folderId":"<demo-folder-id>"}'
# Watch SSE:
curl -N http://localhost:8787/rpc/wiki/streamCompileEvents?compileRunId=<id>
```

Time the wallclock from `CompileStarted` to `CompileFinished`.

- [ ] **Step 2: If wallclock > 60 s, adjust:**

- Increase Researcher concurrency (already parallelized via `Promise.all` in 2.B Task 10 — check it's actually running concurrently; the cap is 6).
- Reduce Drafter context size: in `draftPage` system prompt, slice each finding's `evidence` to ≤ 600 chars instead of 800.
- Skip `BacklinkResolved` events on intermediate ConceptPages — only emit summary stats at the end of `linking`.
- Pre-warm the KV cache by calling `getWiki` once after the previous compile.

- [ ] **Step 3: If still > 60 s, accept it and call out in the video**

Per the storyboard, compile theater visuals are part of the show. If real wallclock is 70–90 s, edit the recording to compress the wait.

- [ ] **Step 4: Re-run determinism gate**

After any prompt edits in Step 2, re-run the determinism test (10/10 catch).

- [ ] **Step 5: Commit any prompt tweaks**

```bash
git add packages/domains/wiki/src/application
git commit -m "tune(3.2): tighten Drafter context for 60s compile budget"
```
