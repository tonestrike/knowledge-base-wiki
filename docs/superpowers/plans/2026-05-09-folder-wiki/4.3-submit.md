## What it does

Connect a Google Drive folder. The agent inspects your documents, **infers a typed wiki schema** for your domain (Decision / Metric / Person / Risk for board governance; Concept / Method / Paper / Open-Question for research), compiles every doc into typed pages with auto-generated indexes, and lets you chat with **answers that adapt to the question** — comparison tables, timelines, charts, key metrics. A separate **Verifier on Opus 4.7** audits every claim against its cited byte ranges in the source — the *span-verifying lint loop* that catches hallucinations before you act on them.

## Three leaps in service of one promise

| Leap | What it does | Trust problem solved |
|---|---|---|
| **Adaptive wiki schema** | Your wiki's *shape* adapts to your domain. PageTypes and Relations generated per folder. | "Generic concept pages don't match how my team actually thinks." |
| **Generative artifact answers** | Your answers' *UI* adapts to the question — tables, timelines, charts, mini-apps. | "Wall-of-text answers are hard to act on." |
| **Span-verifying lint loop** | Every claim is provably grounded. Different model audits Claims against Spans; flags + fixes mismatches. | "I can't trust LLM-summarized knowledge — what if it's wrong?" |

## Repository layout

```
apps/
  api/                # @app/api — Hono on Workers, mounts the oRPC router
  web/                # @app/web — Vite + React + TanStack Query
packages/
  contracts/          # @package/contracts — oRPC contract definitions
  shared-kernel/      # @package/shared-kernel — Clock, Result, EventBus, Anthropic adapter
  domains/
    ingestion/        # @domain/ingestion — Drive, Source, Span
    wiki/             # @domain/wiki — Compile pipeline, WikiSchema (adaptive), 4-subtype WikiPage
    chat/             # @domain/chat — Conversation, Turn, generative Artifact registry
    verification/     # @domain/verification — span-verifying lint loop
  tooling/
    biome/            # shared Biome config
    tsconfig/         # shared TS config
```

Cross-domain imports are forbidden. Coordination is via `@package/contracts` (sync) or domain events on `@package/shared-kernel`'s EventBus (async). Each context owns a `glossary.md` + `.cspell/glossary.txt`; cspell runs with `addWords: false` to enforce linguistic discipline.

## Known limitations (would-ship-next)

- Single-user OAuth. Multi-tenant isolation is the obvious next.
- ~100-doc context-fit ceiling. Embeddings as a fallback retrieval substrate beyond that.
- In-flight CompileRuns lost on Worker eviction. Persistent DO checkpointing is straightforward.
- No incremental compile via Drive webhooks; manual re-compile only in v1.

These are called out in the demo's trade-offs section as "what I'd ship next for you," not as cuts.
