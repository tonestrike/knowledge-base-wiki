# Slice 4.2 — Record

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Capture the 10–20 minute unlisted YouTube submission video that is the actual deliverable of this take-home. Storyboard target is 12 min, 16 min cap. Backups for each Moment captured separately so a live demo glitch doesn't sink the take.

**Architecture:** No code. Recording + editing + upload, working from `docs/projects/folder-wiki/storyboard.md`'s beat-by-beat. Output: an unlisted YouTube URL committed to the repo's README in 4.3.

## Task 1: Recording environment setup

- [ ] **Step 1: Hardware**

- [ ] External monitor at 1920×1080 or higher, set to 100% scale (high-DPI screen recordings often look blurry on YouTube)
- [ ] Microphone tested at the rehearsed cold-open volume (RØDE / good USB condenser; avoid laptop mic)
- [ ] Quiet room, AC off, phone on Do Not Disturb

- [ ] **Step 2: Browser**

- [ ] Use a clean Chrome profile with NO extensions, devtools-closed, bookmark bar hidden
- [ ] Window sized to exactly 1440×900 (so the recording crops cleanly)
- [ ] Dev tools off
- [ ] Drive logged in to the dev account that owns the demo folder

- [ ] **Step 3: Recording software**

- [ ] OBS Studio configured for `1920x1080 @ 30fps`, source: browser window only (not full screen — keeps the menu bar out)
- [ ] CMD-line audio passthrough verified (`-c:a copy` style — re-encoding mic noise after the fact is painful)
- [ ] Test recording: 30 seconds of demo navigation + audio. Play back, confirm sync, no clipping.

- [ ] **Step 4: Pre-warm the live URL**

```bash
open https://tenex-api.<workers-domain>.workers.dev/wiki/<wikiId>
```

Click around for 60 seconds — load every WikiPage type, open one citation modal (warms PDF.js worker), open the chat, run a question. The cache is now hot. Close everything except the home page.

## Task 2: Capture three Moment backups

> Even if the main take goes great, having clean backup recordings of each Moment is what keeps the editing room from being a nightmare.

- [ ] **Step 1: Moment 1 — Schema reveal + compile theater**

Reset the demo folder by clicking "re-compile" (or POSTing `wiki.startCompile` again — D1 keeps the prior runs but a new one starts fresh). Record 0:00 → 2:30 of:

1. Cold-open phrasing (rehearsed) over a static black screen / project hero.
2. Paste the Drive folder URL into the picker.
3. SchemaInferred banner pulses in (`This folder is about board governance...`).
4. Compile theater fans out; source cards fly across; pages emerge on the right; per-PageType IndexPages light up at the end.
5. Click "Decisions" IndexPage → list of all Decisions → click one → magazine ConceptPage with sidebar citations.

Save: `~/Desktop/folder-wiki-backups/moment-1.mov`.

- [ ] **Step 2: Moment 2 — Generative artifact answer + citation flight**

From the open ConceptPage, click "Chat" in the header. Record 3:00 → 4:30 of:

1. Type the rehearsed question: *"What's our Q3 NRR trajectory and how does it compare to our targets?"*
2. Answer streams in: prose → ComparisonTable (Q1 / Q2 / Q3 with target / actual / variance / sparkline) → prose → KeyMetric.
3. Click the citation chip on the "Q3 Actual = 110" cell → chip flies into the PDF.js modal → Span lights up in-doc.
4. Close modal → chip returns to position.

Save: `~/Desktop/folder-wiki-backups/moment-2.mov`.

- [ ] **Step 3: Moment 3 — Lint catches the planted hallucination**

Navigate to `/wiki/<id>/lint`. Record 4:30 → 5:30 of:

1. Click "Run audit". Lint stream events tick in.
2. Verifier flags one Claim asserting NRR was 110%; cited Span says 105%.
3. Ribbon expands: Claim text on the left, cited Span verbatim on the right, inline-diff Correction below.
4. Click "Apply correction" → page updates with motion → ribbon dismisses with a satisfying snap.

Save: `~/Desktop/folder-wiki-backups/moment-3.mov`.

## Task 3: Record the main take

- [ ] **Step 1: Final pre-flight**

- [ ] Storyboard `docs/projects/folder-wiki/storyboard.md` open on the second screen
- [ ] Backup recordings exist (above)
- [ ] Demo wiki pre-compiled and visible at `/wiki/<wikiId>`
- [ ] Mic levels checked
- [ ] Coffee — but not too much

- [ ] **Step 2: Take 1 — full 12-min walkthrough**

Follow the beat-by-beat:

| Time | Beat | What to say (paraphrased — be yourself) |
|---|---|---|
| 0:00–0:30 | Cold open | "Your team's knowledge is in Drive. RAG hallucinates. Notion is manual. We compile your folder into a wiki you can trust." |
| 0:30–0:45 | Folder pick | "Paste a Drive folder URL." |
| 0:45–1:05 | Schema reveal | "The agent reads the folder and decides the *shape* of your knowledge — Decision, Metric, Person, Risk." |
| 1:05–2:30 | Compile theater | "Six agents fan out in parallel. Researcher per source, Drafter, Linker, IndexBuilder. The wiki tree fills in front of you." |
| 2:30–3:00 | Browse | "Every folder gets a different shape. A research lab folder would have Concept, Method, Paper, Open Question. The wiki adapts." |
| 3:00–3:15 | Question | "Ask the wiki anything." |
| 3:15–4:00 | Artifact answer | "The answer isn't a wall of text. It picks the right component — table, chart, key metric. Every cell cited." |
| 4:00–4:30 | Citation flight | "Click any chip. The citation flies into the source PDF. Span anchored to the byte range. You can verify every claim." |
| 4:30–5:30 | Lint catches | "Now the reliability story. We run a different model — Opus — over every claim. It flags the one we got wrong. Inline diff. Apply." |
| 5:30–7:30 | Trade-offs | "What I'd ship next for you: incremental compile via Drive webhooks, embeddings as a fallback substrate beyond ~100 docs, multi-tenant isolation, voice mode on the chat." |
| 7:30–9:30 | Tech stack | "Bun + Turborepo. Hono on Cloudflare Workers + Durable Objects + D1 + R2. oRPC contract-first. Vite + React + TanStack Query. Anthropic SDK. Domain-driven design." |
| 9:30–11:30 | Architectural decisions | "Why DDD: the wiki, chat, ingestion, and verification contexts each have their own language and aggregate invariants — they coordinate via typed contracts and events, never imports. Why contract-first: it let me parallelize the implementation across five tracks. Why three leaps in service of one promise: knowledge you can trust." |
| 11:30–12:00 | Close | "Knowledge work is moving from RAG-on-chunks to compiled, typed, verified wikis. Every claim provably grounded. Thank you." |

Save: `~/Desktop/folder-wiki-takes/take-1.mov`.

2. Cut any dead air or stumbles longer than ~1 second.
