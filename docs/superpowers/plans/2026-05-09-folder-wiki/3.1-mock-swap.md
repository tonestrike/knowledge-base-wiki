# Slice 3.1 — Mock-swap + end-to-end

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (this is sequential integration). Steps use checkbox (`- [ ]`) syntax.

**Goal:** Prove the contract spike's promise. With Phase 2 merged, MSW disappears in production builds, the web app talks to live `apps/api`, the SSE streams flow through Durable Objects to the browser, the citation flight renders against signed R2 URLs, and the latency targets hold.

**Architecture:** Two production-mode toggles plus an R2 proxy:
1. MSW only starts in `import.meta.env.DEV && import.meta.env.VITE_USE_MOCKS !== '0'`. The build pipeline sets `VITE_USE_MOCKS=0` in `apps/web` builds destined for production.
2. `apps/api` proxies `GET /r2/sources/:sourceId/raw` → signed R2 GET, with a short TTL signed URL. The web app's `CitationModal` already points at this path.
3. End-to-end script wires Drive → Compile → Wiki → Chat → Lint and asserts all 5 spec acceptance criteria.

**Tech Stack:** No new tech.

## Task 3: R2 proxy for source raw bytes

**Files:**
- Create: `apps/api/src/r2-proxy.ts`
- Modify: `apps/api/src/index.ts`

- [ ] **Step 1: Implement proxy**

```ts
// apps/api/src/r2-proxy.ts
import type { Hono } from 'hono';

interface Env { STORAGE: import('@cloudflare/workers-types').R2Bucket }

export const mountR2Proxy = (app: Hono<{ Bindings: Env }>): void => {
  app.get('/r2/sources/:sourceId/raw', async (c) => {
    const id = c.req.param('sourceId');
    const obj = await c.env.STORAGE.get(`sources/${id}/raw`);
    if (!obj) return c.notFound();
    const headers: Record<string, string> = { 'content-type': 'application/pdf', 'cache-control': 'private, max-age=300' };
    return new Response(obj.body, { headers });
  });

  app.get('/r2/sources/:sourceId/text', async (c) => {
    const id = c.req.param('sourceId');
    const obj = await c.env.STORAGE.get(`sources/${id}/text`);
    if (!obj) return c.notFound();
    return new Response(obj.body, { headers: { 'content-type': 'text/plain; charset=utf-8' } });
  });

  app.get('/r2/sources/:sourceId/outline.json', async (c) => {
    const id = c.req.param('sourceId');
    const obj = await c.env.STORAGE.get(`sources/${id}/outline.json`);
    if (!obj) return c.notFound();
    return new Response(obj.body, { headers: { 'content-type': 'application/json' } });
  });
};
```

test.describe('folder-wiki end-to-end', () => {

  test('compile → browse → chat → cite → lint apply', async ({ page }) => {
    await page.goto('/');
    // Real auth token would be needed for production; test environment hits the
    // already-registered demo folder via a seeded /e2e/seed endpoint.
    await page.goto('/wiki/22222222-2222-4333-8444-555555555555');

    // Compile theater pulses in the SchemaInferred banner within 5s
    await expect(page.getByText(/PageTypes:.*Decision/i)).toBeVisible({ timeout: 60_000 });
    await expect(page.locator('text=Schema inferred')).toBeVisible({ timeout: 30_000 });

    // First IndexPage materializes
    await expect(page.locator('text=Decisions').first()).toBeVisible({ timeout: 60_000 });

    // Open a Decision page
    await page.locator('a:has-text("Decision:")').first().click();
    await expect(page.getByRole('heading', { level: 1 })).toBeVisible();

    // Click a citation chip — modal opens with PDF
    await page.locator('button:has(span.bg-accent)').first().click();
    await expect(page.locator('canvas')).toBeVisible();

    // Close modal
    await page.keyboard.press('Escape');

    // Chat
    await page.goto('/chat/new');
    await page.getByPlaceholder('Ask the wiki…').fill("What's our Q3 NRR trajectory?");
    await page.getByRole('button', { name: 'Ask' }).click();
    await expect(page.locator('table')).toBeVisible({ timeout: 30_000 });

    // Lint
    await page.goto('/wiki/22222222-2222-4333-8444-555555555555/lint');
    await page.getByRole('button', { name: 'Run audit' }).click();
    await expect(page.getByText('unsupported')).toBeVisible({ timeout: 90_000 });
    await page.getByRole('button', { name: 'Apply correction' }).click();
  });
});
